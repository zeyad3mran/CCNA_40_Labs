# Lab 01: Building a Simple Network Between Two PCs and One Switch

**Section:** Networking & Switching Fundamentals
**Tool:** Cisco Packet Tracer

## 🎯 Objective
Verify basic connectivity between two devices on the same network using a single switch.

## 🧰 Devices Used
| Device | Qty |
|---|---|
| PC | 2 |
| Switch 2960 | 1 |

## 🗺️ Steps
1. Connect the two PCs to the switch using a Straight-Through cable.
2. Configure an IP address and subnet mask on each PC (Desktop → IP Configuration).
3. Test connectivity from PC0 to PC1 using `ping`.

## ✅ Expected Result
You should get a Reply from PC1, confirming Layer 2 connectivity and correct IP addressing.
